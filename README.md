# MediSecure-Health-Telehealth-EHR-System
MediSecure Health is a modern, microservice-ready Telehealth &amp; Electronic Health Records (EHR) Web API built with C# and .NET 8. It is intentionally designed as an educational reference target for Threat Modeling and Architectural Vulnerability Analysis (STRIDE, DFD Level 0/1, OWASP API Top 10, CWE, DREAD Risk Scoring).
