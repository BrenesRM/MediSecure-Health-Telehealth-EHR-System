# MediSecure Health (.NET 8 C# Web API)
## Threat Modeling & Vulnerability Analysis Reference Target

This solution is designed for **CS 340 Secure Software Development (Deliverable 1 - Week 4)** at ULACIT.

### Quick Start:
1. Open `MediSecureApi.sln` in **Visual Studio 2022**.
2. Press **F5** or `Ctrl+F5` to build and run.
3. Access:
   - **Interactive Web Portal**: `http://localhost:5000`
   - **Swagger OpenAPI Docs**: `http://localhost:5000/swagger`
